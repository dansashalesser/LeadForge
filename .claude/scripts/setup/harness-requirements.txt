# harness-requirements.txt — Python packages the HARNESS ITSELF imports.
#
# These are installed into the harness-owned venv (<harness root>/.venv-tools),
# NEVER into a target repo. A repo's dependency prune, lockfile regen, or
# `uv sync` cannot touch them, because the repo never declared or contained them.
#
# Consumed by: scripts/setup/check-harness-deps.sh
# Format: <pip-spec> [import-name]
#   import-name defaults to <pip-spec> with '-' → '_' and any version spec stripped.
#   Give it explicitly whenever the distribution name != the module name.
#
# NOT listed here (owned elsewhere on purpose):
#   liteparse   — scripts/setup/liteparse-setup.sh (same venv, own fallback logic)
#   headroom-ai — scripts/setup/headroom-setup.sh (global uv tool; hooks call its
#                 own interpreter, so it is already prune-immune)
#   anthropic   — removed 2026-08-20. The only two importers (session/micro_reflect.py,
#                 session/detect_reexplanation.py) now shell out to `claude --print`,
#                 which authenticates with the user's Claude subscription. The SDK
#                 needs an ANTHROPIC_API_KEY billed separately per token, and with no
#                 key set it raised on every invocation — the memory-gap detector was
#                 dead for its entire deployment and reported as "0 gaps".
#
# Nothing is currently listed. The file is kept so the next harness-owned dependency
# has an obvious home; check-harness-deps.sh tolerates an empty list.
